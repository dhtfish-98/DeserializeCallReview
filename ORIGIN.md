This attribution describes provenance and does not imply upstream endorsement or independent human authorship of AI-generated code.

Bandit's selected mechanism qualifies imports and checks a blacklist or YAML Loader leaf spelling. The new mechanism uses lexical block binding tables, scope-aware aliases, deferred free-binding checks, actual nominal SafeLoader import bindings, bounded input and a privacy-reduced report. A same-spelled custom/unknown Loader remains OPEN. Bandit's platform/plugin execution, issue severities, configuration, target discovery, baselines and other blacklist families are intentionally outside this selected rewrite.

Behavior differs deliberately. Global and closure rebinding after a definition is OPEN. Function locals are recognized across the entire block, including exception/match/loop bindings; methods skip class locals when resolving free variables. Unknown callbacks/context managers and mutable module attributes invalidate selected nominal bindings. Generator/comprehension timing, annotation evaluation, branches and termination are not executed; they receive OPEN accounting. Fixed upstream examples retain every selected original event as a REVIEW or a canonical-candidate OPEN row; they are **not** claimed to match Bandit issue counts or severities.

Source-read evidence, local behavioral tests, built artifacts, remote CI execution and CVP eligibility are separate claims. Artifact metadata does not establish runtime exploitability or approval. CVP eligibility and any safety-classifier outcome remain OPEN.
